## 基本情况

- 一句话：π0.6 基座（5B VLM + action expert）+ Recap（RL 配方）= 会从自己实践经验中进步的 VLA
- π0.6 基座：π0.5 的精炼版，backbone 略大（5B），支持异构提示（文字指令 + 执行质量标注 + 动作 advantage）
- 定位跃迁：π0 时代"演示里能做成" → π*0.6"一整天续航、进工厂干活"

## ① 动机：为什么模仿学习不够

三步学艺类比：
1. 看示范（模仿）→ 能成功"一半时间"
2. 被纠正（教练）→ 修复合
3. 自己练（强化）→ 肌肉记忆

病根：**复合误差**（compounding errors）——小错 → 进入训练分布外的状态 → 更大的错 → 失败。
LLM 无此问题（静态输出，不与环境交互）；VLA 是控制策略，持续交互，独有此病。
引 arXiv 1011.0686（DAgger，2010 年就理解了此问题）。

## ② 方法：Recap

**R**L with **E**xperience & **C**orrections via **A**dvantage-conditioned **P**olicies

| 通道 | 数据 | 作用 |
|---|---|---|
| 示范 | 人遥操作（原有） | 学会做 |
| 纠正 | 策略自己跑，犯错时人接管 | 监督"策略自己陷入的处境"——正中复合误差 |
| 强化 | 自主 episode + 结果标签 | 自我精进 |

**核心难点：credit assignment**。手柄插不进——错在几十步前的抓取角度。
解法：
1. 训 value function（预测离完成还有多少步/多好）
2. advantage = 动作前后 value 变化
3. **advantage-conditioned VLA**：训练时好坏数据全保留、标注 advantage 喂入；推理时指令"执行高 advantage 动作"
   - 亮点：差数据不丢弃，标低 advantage 照样训练——模型从失败中学习
   - 与 Dreamer 的 V_λ 同源概念，但搬进了 VLA 的提示空间

## 与谱系的连接

- π0（模仿）→ π0.5（开放世界泛化）→ π0.6（更大基座+异构提示）→ **π*0.6（+RL：纠正+经验）** → π0.7（组合泛化）
- π0.7 博客明确说：π0.7 开箱即用达到 π*0.6 RL 微调专家的水平
- 呼应 FDM 论文的批评："VLA 学了怎么做，没学做了会怎样"——π*0.6 用 RL 从结果回传信号，是另一条补法
