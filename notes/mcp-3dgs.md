# MCP-3DGS：基于 3D Gaussian Splatting 与 MCP 协议的具身空间智能世界模型

- **路线标签**：空间表征 × 主动感知 × 三维规划（3DGS World Model + Model Context Protocol）
- **核心公式**：$\text{Embodied Agent} = \text{Spatial Representation (Semantic 3DGS)} \times \text{Perception} \times \text{Planning} \times \text{Action}$
- **一句话**：把真实 RGB-D 场景重建出的各向异性语义 3D 高斯场封装为标准化 `FastMCP` 工具集，让 VLM/LLM 大脑能在显式三维世界里做**开放词汇定位**、**移动前候选视角想象（VLN NBV）**、**ESDF 无碰撞三维路径规划**与**反事实三维场景编辑**。
- **代码仓库**：[`yimingjiang216-alt/mcp-3dgs`](https://github.com/yimingjiang216-alt/mcp-3dgs)（基于 TUM `rgbd_dataset_freiburg1_desk` 真实传感器序列）

---

## 一、两问定位法

1. **它预测/表征的是什么空间？**
   **显式三维语义高斯空间 + 多模态投影空间**：每个基元 $G_i = (\mu_i, \Sigma_i, \alpha_i, c_i, \text{id}_i, e_i \in \mathbb{R}^{384})$ 同时承载度量几何（位置与切平面各向异性协方差）、外观辐射（RGB）、不透明度（物理占据）与 384 维开放词汇语言嵌入（`all-MiniLM-L6-v2`）。
2. **预测出来给谁用？**
   **给 VLM/LLM 决策大脑当「可查询、可预演、可编辑的外部三维空间记忆与模拟器」**：
   - **当空间检索器**：`query_3d_object("something to drink coffee from")` 直接返回三维包围盒与世界坐标；
   - **当主动感知预演场（VLN Imagination）**：`imagine_candidate_views` 在物理移动相机前，在 3DGS 中并行渲染 6 个候选视角，选出无遮挡率最高、构图最居中的最佳下一视角（NBV）；
   - **当安全规划器**：`plan_collision_free_path` 从不透明度高斯导出三维欧氏符号距离场（ESDF），用安全加权 26 邻域 3D A* 规划零碰撞三维轨迹；
   - **当反事实沙盘**：`edit_3d_object` 直接对目标物体的三维高斯子集施加 $\text{SE}(3)$ 平移/旋转或移除，预览操作后的遮挡与几何布局。

## 二、它修了前人的什么

| 传统路线痛点 | MCP-3DGS 的解法 |
|---|---|
| **2D VLM 只有图像平面记忆，缺三维持久坐标与遮挡推理** | 用 Mask R-CNN v2 多视角 2D 实例掩码 + 深度一致性门控反投影 + 3D 聚类，建立持久化三维物体实例（`21` 个桌面/办公实例） |
| **NeRF 隐式 MLP 慢且不可局部编辑、难导出碰撞体积** | 用显式各向异性 3D 高斯球（`45,000` 个基元）：既能毫秒级 EWA 协方差投影渲染 RGB/深度/语义图，又能直接转三维 ESDF 距离场并对单个物体做刚体变换 |
| **VLN 导航盲目试错移动，遇到遮挡才发现看不见** | 移动前先在 3DGS 世界模型中想象候选视角（`imagine_candidate_views`），将目标平均无遮挡率从 `67.91%` 提升至 `99.66%`（其中严重遮挡的笔记本从 `4.59%` 提升至 `100%`） |
| **真实 RGB-D 序列（TUM `fr1/desk`）起始深度流滞后导致鬼影** | 定位到 `depth.txt` 比 `rgb.txt` 晚启动 `0.582s`（18 帧），引入 $|\Delta t| \le 25\text{ ms}$ 严格时钟门控 + 多视角自由空间光线雕刻（`violate == 0`）+ 前表面深度门控 EWA 溅射，将留出视角深度 RMSE 从 `16.51 cm` 压到 `7.39 cm`（`-55.2%`），PSNR 提升至 `16.98 dB` |

## 三、关键实测数字（TUM `fr1/desk`）

- **场景规模**：`45,000` 个各向异性三维高斯，`21` 个持久化三维物体实例，`613` 帧相机轨迹（`10.74 m`）
- **留出视角渲染与几何消融（10 个未见测试视角）**：
  - **Ours（各向异性 EWA + 自由空间雕刻 + 前表面门控）**：`PSNR = 16.98 dB`，`SSIM = 0.4001`，`Depth RMSE = 7.39 cm`，表面覆盖率 `89.01%`
  - **各向同性点溅射基线**：`PSNR = 11.49 dB`，`SSIM = 0.1798`
  - **未做时钟同步门控与自由空间雕刻**：`PSNR = 10.85 dB`，`Depth RMSE = 16.51 cm`
- **384 维开放词汇三维目标定位（12 条功能/方位自然语言查询）**：**Top-1 准确率 `100.0%`（12/12）**，平均综合定位得分 `0.7614`
- **VLN 主动候选视角想象（6 类目标 × 6 候选视角）**：平均目标像素占比从 `1.84%` 提升至 **`4.05%`（2.20×）**，无遮挡三维高斯率从 `67.91%` 提升至 **`99.66%`**，NBV 效用得分从 `0.4875` 提升至 **`0.7623`（+56.4%）**
- **3DGS-to-ESDF 三维无碰撞轨迹规划（8 项跨桌面操作任务，安全半径 $5.5\text{ cm}$）**：**无碰撞达标率 `100.0%`（8/8）**，平均最小障碍物间隙 **`8.13 cm`**（直线插值基线仅 `37.5%` 达标、最小间隙 `3.71 cm`）

## 四、在认知架构中的位置

- **所属层级**：**大脑（空间记忆 + 主动感知预演 + 工具编排）**
- **与本库其他模块的关系**：
  - 向上承接 [`rgbd-slam`](https://github.com/yimingjiang216-alt/rgbd-slam)（提供相机位姿与稀疏地图）与 [`sfm-3dgs-pipeline`](https://github.com/yimingjiang216-alt/sfm-3dgs-pipeline)（提供 3DGS 表征）；
  - 横向补齐 [`notes/01-认知架构.md`](01-认知架构.md) 中**大脑层的四项核心标准**：① 主动生成中间观测目标（NBV 视角）② 在 3DGS 世界模型中预演并比较视角与反事实编辑后果 ③ 调用外部空间工具与持久三维记忆（FastMCP）；
  - 向下为运动皮层（VLA）与小脑（[`supermimic-g1-sim`](https://github.com/yimingjiang216-alt/supermimic-g1-sim) 全身控制器）提供世界系下的无碰撞三维路点与目标位姿。
