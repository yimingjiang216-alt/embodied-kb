## 导航路线（VLN：语言 + 视觉 → 走）

| 论文 | 年份 | 一句话 | 关键遗产 |
|---|---|---|---|
| **VLN-CE** | 2020-04 | 从"全景图节点跳转"搬到连续 3D 环境 | **量化图先验：手工 agent 16.3%→3%**；深度是命根子（去掉 20%→4%）；首个纯策略无预测任务 |
| **VLN 综述** | 2024-07 | 基础模型时代的 VLN 全景 | 三层框架：世界模型（记忆/泛化）/ 人类模型（歧义/grounding）/ 智能体（推理/规划） |
| **NaVid** | 2024-02 | 视频 VLM 做 VLN，**不用地图/里程计/深度** | 只靠单目 RGB 到 SOTA（SPL 35.9%）；真机 66%；**VLM 自带空间理解 → 深度不再是命根子** |

操作 vs 导航的分野：**操作**=6D 末端动作、秒级、灵巧/接触；**导航**=底盘动作、几十上百步、记忆/探索/定位。

**导航线的范式转折**：VLN-CE 时代"没深度学不会"（20%→4%）→ NaVid 时代"不用深度反而更泛化"（37.4%）——基础模型把空间理解打包进了预训练表征。

**三维定位法（综述框架，可与两问叠用）**：环境（世界模型）/ 人（指令理解）/ 自己（推理规划）。

## 数据来源四分法（学具身智能必须分清）

```
① 遥操作采集（真实）   ← π0 的 1 万小时、OpenVLA 的 97 万条
② 仿真采集           ← Isaac Lab：RL 无限跑 + Mimic 重组演示
③ 神经合成           ← DreamGen 的视频世界模型生成
④ 人类视频（无标注）  ← Genie 从互联网视频学
```

四条路成本、覆盖面、真实性各不同——这正是"通用机器人"缺数据的全貌。

## 三个反复出现的机制（跨论文）

- **CFG（classifier-free guidance）**：π0 动作生成 → π*0.6 advantage 条件化（论文自称 RL 版 CFG）→ π0.7 元数据引导
- **stop-gradient vs 梯度全通（2026 配方之争）**：π0.5 KI 隔离离散动作梯度防干扰 → Wall-OSS 论证"干扰是需要的"（离散 CE 当梯度桥），消融显示隔离版掉 25 点
- **分布式 value / twohot**：DreamerV3 → π*0.6（201 bins）——多峰回报不被平均
- **复合误差及其修法**：UniPi 开环 → DreamZero 真帧回写 KV → V-JEPA 2 teacher-forcing → FDM 架构级单向
- **动作接口的来源**：环境给（World Models）→ 交互采（Dreamer）→ **从视频学（Genie 1 的 8 键 → LAPA → DreamGen/GR00T）**→ 语言描述（Argon+Omni）
- **未来当老师的三种解法**：FDM 监督动作特征 → LingBot 2.0 双查询蒸馏（深度+视频老师，独立查询不搅动动作路）→ π0.7 BAGEL 目标图（当条件不当老师）——同一问题的三种注入位置
- **离散 token vs 连续生成（VLA 两大流派）**：RT-2 → **OpenVLA（256 bins 覆盖词表末 256 token）** → FAST（DCT+BPE 压缩）→ Wall-OSS RVQ ｜对撞｜ π0 flow matching → GR00T → π0.7；OpenVLA 派胜在可复现/消费级，π 派胜在性能上限
- **sim2real 差距的归因链**：执行器建模（Isaac Lab 明言主因：电机延迟/力矩上限）→ 渲染与物理错配 → 域随机化不足；另有一条易忽略的是**观测/控制频率偏离训练分布**（OpenVLA 的 int8 掉点即此：1.2Hz vs 训练 5Hz）
- **分数里有多少是环境白送的（通用判断线索）**：VLN 图先验（手工 agent 16.3% vs 连续环境 3%）→ Isaac Lab 的 sim2real 归因 → OpenVLA 的频率偏离——看论文高分时先问这个

## 2026 前沿的形状

每个系统都是"会推理的 + 懂物理的"缝合，差别在谁当主体：
- π0.7 = VLA 主体 + 世界模型当目标想象器
- Argon = LLM 主体 + 世界模型当工具
- FDM = 动作策略主体 + 世界模型只当老师
- DreamZero/VPP2 = 世界模型本身就是策略（WAM）

## 空缺（领域现状）

- 没有既精确又广泛的世界模型（MuJoCo 精确狭窄 / 视频模型广泛不可靠）
- "视频生成=世界模型"之争未决：正方证据 VPP2 正相关实验、DreamGen 基准相关；反方 LeCun/V-JEPA
- 术语未统一：world model / dynamics model / simulator / WFM 混用

### 三个阶段（时间线的宏观读法）

1. **2018-2023：世界模型独大**——所有工作都在回答"怎么在潜空间里预测未来"，操作和导航两条线各自发展（World Models→Dreamer 系；VLN→VLN-CE）
2. **2024：VLA 元年**——Genie/NaVid/OpenVLA/π0 四个月内出现，范式从"预测未来"转向"直接学策略"；导航线也被 VLM 接管（NaVid 不用深度了）
3. **2025-2026：缝合期**——已经不满足于单一范式：WAM（世界模型+动作）、FDM（未来只当老师）、Isaac Lab（数据基建）、LingBot/Wall-OSS（架构之争）
