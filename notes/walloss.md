# 精读笔记 · Wall-OSS 0.5

> arXiv 2605.30877 · 小鹏（X-Square-Robot/wall-x 开源）· 2026-05 · 技术报告

## 基本情况

- 路线：**VLA（"预训练即能力"派）**
- 一句话：4B 开源 VLA（Qwen2.5-VL-3B + MoT Action Expert），证明预训练本身直接产出真机行为——微调前零任务数据完成 17 任务套件若干个
- 核心问题：所有 VLA 论文都报微调后的数字——预训练本身到底产出什么？只是更好的初始化，还是已经会干活？
- 对标：微调后 15 任务 60.5% vs π0.5 43.0%（+17.5）、DreamZero 33.4%（+27.1）

## 架构

- Qwen2.5-VL-3B 当 VL Expert；新增 Action Expert（MoT，同 π0.5/VPP2 的 MoT 思路）→ 4B+
- 视觉/语言/本体/离散动作 token 走 VL Expert；带噪连续动作走 Action Expert
- **与 π 系关键区别**：π0 KI recipe 用 stop-gradient 隔离；Wall-OSS 让梯度全通——论证"干扰恰恰是需要的"
- 注意力 mask：离散/连续动作 token 互不可见（可独立训评）；26 维动作（双臂末端 20 + 底盘 3 + 升降 1 + 头 2），6D 旋转

## 训练配方：梯度桥接协同训练（灵魂）

```
L = L_flow + 0.01·L_act-CE + 0.01·L_mm-CE
        ↑            ↑             ↑
   部署接口      梯度桥（塑造主干）  锚（保 VLM 能力）
```

- 张力起点：flow matching 梯度太弱推不动主干；离散 CE 梯度强但不能直接执行
- 梯度分析：中后期 flow 对主干更新只占 ~5%，主力是两个 CE；act-CE 与 flow 梯度正相关（桥的本质），mm-CE 近似正交（不抢戏）
- Action-Space Supervision：损失定义在恢复的动作上而非速度场 = (1−τ)² 加权 → 强调高噪声区（低频轨迹形状决定上限）；τ 采样与 π0 一字不差（Beta(1.5,1), s=0.999）
- RVQ 动作 tokenizer 替换 FAST：加视觉对齐 + 下一帧预测 + DCT 抑抖；消融单项 29.3%→48.1%
- Muon 优化器 + 自研 DMuon 分布式（优化器开销降 100×）

## 数据

- 自采（双臂/移动/XRZero-G0 无本体采集器）+ 开源 10 家（RoboMIND/AgiBot/DROID/Bridge/RT-1…）
- 平方根采样（p=0.5）平衡长短尾——π0 n^0.43 同族
- 多模态 90M：其中 **1200 万"具身桥数据"**（从动作轨迹造的 VQA/grounding，物体/空间/场景/任务四级）——"锚"的实现，防 VQA 崩
- 每 epoch 100 万+轨迹，batch 8192

## 零样本结果（无微调，17 真机任务）

| 层 | 例子 | 进度 |
|---|---|---|
| 精通 ≥60% | 积木分色 100%、水果分拣 96%、套环 86%、**拉绳收紧（未见可变形）82%** | 语义类最强 |
| 部分 40-60% | 按开关 55% | 会抓会移，差精确一步 |
| 够不着 <20% | 叠毛巾 10%、插充电器 9% | 精细+分布稀疏 |

- held-out 与 seen 同步上升（24.2→53.6 vs 26.1→50.0）→ 迁移非背模板
- 阶梯式涌现（积木分色中途 50%→100%）——LLM 涌现的机器人版
- 诚实声明："unseen 是相对的"（开源数据可能有语义相近经验）
- 多模态代价：具身 grounding +21.8 / 通用 VQA −15.0——明确认了特化 trade-off

## 谱系定位

- 两问：预测离散动作 token（训练）+连续动作（部署），不预测未来画面——纯 VLA
- 与 π 谱系的交锋：π 的"预训练见多识广/后训练学会干活"分工 → Wall-OSS 模糊化分工（预训练即行为）
- 与 FDM 问题互补：FDM 问"未来信号怎么用"，Wall-OSS 问"动作信号塑造了什么"（答案：桥+锚）
- 2026 VLA 训练配方之争最清晰的一次交锋：stop-gradient vs 梯度全通，带开源权重可验证
