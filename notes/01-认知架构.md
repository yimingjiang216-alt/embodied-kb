# 认知架构：大脑 / 运动皮层 / 小脑

> 这份笔记不是某篇论文的摘要，是从本库 26 篇论文里提炼出的**横向分析框架**。
> 用途：给任何具身系统定位"它在这个架构里处于哪一层、能力上限在哪"。
> 与两问定位法（预测什么/给谁用）正交——两问是**功能轴**，这份是**层级轴**。

## 一、三层结构

```
┌──────────────────────────────────────────────┐
│ 大脑（决策层）                                 │
│   输出：子目标 / 代码 / 意图                    │
│   时标：秒级                                    │
│   候选：VLM（感觉皮层）/ LLM（规划）/ WAM（预演） │
├──────────────────────────────────────────────┤
│ 运动皮层（意图层）                             │
│   输出：动作块（action chunk）                  │
│   时标：毫秒级                                  │
│   代表：VLA（π0/OpenVLA/GR00T/Wall-OSS...）    │
├──────────────────────────────────────────────┤
│ 小脑（控制层）                                 │
│   输出：关节指令 / 力矩                        │
│   时标：微秒-毫秒                               │
│   代表：MPC / WBC / 阻抗控制 / PID             │
└──────────────────────────────────────────────┘
```

**判据只有一条：看它输出什么。**
- 输出「力矩/电流」→ 小脑
- 输出「动作块/末端位姿增量」→ 运动皮层
- 输出「子任务/代码/目标图」→ 大脑

## 二、本库的层级分布（26 篇）

| 层级 | 论文 | 说明 |
|---|---|---|
| **大脑-工具编排** | Argon | LLM 写代码操纵 MuJoCo/Omni，秒级多轮 |
| **大脑-目标想象** | π0.7（BAGEL 生成子目标图） | 最轻量的大脑：只生成一张图 |
| **大脑-反思** | π\*0.6（Recap） | 从 rollout 学 advantage，知道自己做得好不好 |
| **大脑-预演** | Dreamer / DreamerV3 / DreamGen / WAM 系 | 在想象里试，但受世界模型精度锁死 |
| **大脑-规划（导航）** | VLN 综述里的 LLM planner 那一派 | 导航线的规划层 |
| **运动皮层** | π0 / π0.5 / OpenVLA / GR00T / Wall-OSS / LingBot / NaVid | 本库主体，全是这一层 |
| **小脑** | ❌ **本库空白** | 经典控制（MPC/WBC/阻抗）一篇没读 |
| **基础设施** | Isaac Lab（仿真器）/ VLN-CE（基准）/ 其他基准 | 不在链路上，但决定链路能跑多快 |

**最重要的发现：本库缺"小脑"这一整层。** 这不是偶然——2024 年后 VLA 领域默认底层控制已解决（Franka 伺服够好），所有人注意力都在"做什么"。但换平台（人形/灵巧手）立刻撞墙，Isaac Lab 里的 WBC 章节就是这个缺口。

## 三、为什么 VLA 不是"大脑"

用四标准检验（本库可验证版）：

| 标准 | 人类大脑 | 现在的 VLA |
|---|---|---|
| ① 主动生成中间目标 | ✅ | ⚠️ 只有 π0.5/π0.7 有雏形 |
| ② 预演并比较后果 | ✅ | ⚠️ 只有 WAM/Dreamer，且只可靠 2-5 秒 |
| ③ 从经历改进 | ✅ | ✅ π\*0.6 有雏形 |
| ④ 调用工具/外部记忆 | ✅ | ✅ Argon（全在外部） |

**四项标准没有一项被完整满足。** 所以准确说法是：**VLA 是"运动皮层 + 语言接口"**，不是大脑。

**神经科学的关键判据**：真正的大脑能在**没见过的情境里推理出新解法，无需梯度更新**。现在的系统全部只会插值——FDM 那篇的批评（"VLA 只在学动作，浪费了未来信号"）就是最硬的旁证。

## 四、大脑对泛化的作用（本库最原创的判断）

### 两种泛化必须分清

| 类型 | 定义 | 获得方式 |
|---|---|---|
| **插值型** | 新场景是训练分布内的**组合** | 靠数据覆盖，堆得越多越强 |
| **外推型** | 新场景在训练分布**流形之外** | 靠推理，大脑干的活 |

**本库所有 VLA 都只做插值型。**

### 三种大脑能力 × 泛化增益

| 能力 | 作用机制 | 增益 | 前提/上限 |
|---|---|---|---|
| **① 预演**（世界模型） | 用想象的多样性换数据多样性 | 大 | **被世界模型精度锁死** |
| **② 反思**（π\*0.6） | 用失败经验换纵向鲁棒性 | 中 | advantage 要准 |
| **③ 中间目标组合**（π0.7） | 把新任务拆成已知可执行的子目标 | **最大** | 子目标要可执行 |

**排序（本库可验证）：③ 中间目标组合 >> ② 反思 > ① 预演**

**为什么预演排最后**：它的质量上限被世界模型精度锁死；而子目标的组合只在逻辑层发生，不依赖物理精度。
**这解释了 FDM 为什么主张"推理时把未来扔掉"**——预演不准时，规划会利用模型误差（World Models 论文的"作弊"分析）。

### 一句话

> **大脑的泛化价值不在"想得更多"，而在"拆得更细"。**

## 五、必须要大脑吗？不需要——但有分界线

| 方案 | 做法 | 代价 |
|---|---|---|
| **① 不要中间层** | OpenVLA/π0 纯反应式 | 上限被数据分布锁死，不知道哪不对 |
| **② 最小中间层** | π0.7 生成一张目标图 | 成本最低（同模型加一次生成），能做组合泛化 |
| **③ 完整大脑** | Argon 式 LLM 编排 | 成本高、秒级延迟、需工程集成 |
| **④ 人在环** | 遥操作（人当大脑） | 能做最复杂任务，但不可扩展 |

**判断标准：试错成本。**
- 试错便宜（仿真/玩具环境）→ 不需要，数据量够就行
- 试错昂贵（真机/医疗/危险作业）→ **至少需要"最小中间层"**（一张目标图）

**性价比最高的答案是 ②**：π0.7 的 BAGEL 目标图证明——不推理、不反思、不预演，只生成一张图当中间层，成本几乎为零，收益是组合泛化。

## 六、本库的真实空缺（这篇笔记的结论）

1. **小脑层完全空白**：经典控制（MPC/WBC/阻抗）一篇没读。VLA 输出"动作块"到"电机力矩"之间发生了什么，本库无一篇讲清
2. **大脑的所有能力都是单点**：π\*0.6 会反思但不会想象；π0.7 会想象但反思是静态的；**没有把"生成目标图"和"从 rollout 学 advantage"合进同一个闭环的系统**
3. **记忆几乎空白**：操作线的 VLA 全是马尔可夫式（只看当前帧）；只有 VLN 线真正处理了历史编码

**最明确的下一步空缺**：把 ② 反思 和 ③ 中间目标 合起来——**能生成目标、又能从失败中学着改目标的系统**。这是从本库 26 篇论文能看出来的、最清楚的一条空白。
