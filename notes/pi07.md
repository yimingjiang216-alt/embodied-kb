## 基本情况

- 路线：**VLA + 可引导（steerable）+ 组合泛化**
- 一句话：π0.6 + MEM 记忆 + 五件套多模态提示（语言/子目标图/速度/质量/控制模式），开箱即用追平 RL 专家
- 架构：Gemma3 4B 主干（含 400M 视觉编码器）+ MEM 历史编码器（6 帧压成单帧 token 数）+ 860M action expert（50 token，flow matching，RMSNorm 注入时间步）

## 五件套提示（核心创新）

```
<多视角观测><多视角子目标图>
Task: peel vegetables. Subtask: pick up the peeler.
Speed: 8000. Quality: 5. Mistake: false. Control Mode: joint.
<本体感受>
```

- 每个组件训练时随机 drop → 推理时任意子集可用
- 子目标图只加到 25% batch（有了它动作预测变成逆动力学，训练快）；这 25% 里再 30% 丢文字子任务
- 元数据（质量 1-5 分 + 失误标签）让次优数据可用：失败 episode 标低分照样训 → 图 18：无元数据时数据越多性能越差，有元数据时持续涨
- 推理时元数据恒设"最快+最好+无失误"；CFG 可对元数据引导（β∈{1.3,1.7,2.2}）

## 世界模型（BAGEL 14B，推理时挂载）

- BAGEL 图像生成模型微调：(观测, 子任务, 元数据) → 子目标图
- 不模拟动力学，只画"这步做完该长什么样"——最弱意义的世界模型
- 异步生成：ℓ̂ 变化或 4 秒计时到才刷新，25 步去噪，不阻塞执行
- 高层策略 = π0.7 自己（观测+任务+历史子任务 → 下一个子任务）

## 关键实验

- 咖啡机开箱即用 = π*0.6 RL 专家水平
- 复杂指代（"捡起我喝汤用的东西"）、反向任务（垃圾进餐桶）——GC（子目标图）关键
- 跨本体：叠衣数据全来自小双臂，UR5e 零数据直接叠；涌现新策略（垂直抓 vs 源平台斜抓）；打平人类专家（80% vs 80.6%）
- 语言教练教新任务（空气炸锅红薯）→ 教练数据训高层策略 → 全自动，零演示
