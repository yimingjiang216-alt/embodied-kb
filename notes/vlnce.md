# 精读笔记 · VLN-CE

> arXiv 2004.02857 · ECCV 2020 · Krantz, Wijmans, Majumdar, Batra, Lee（俄勒冈州立/佐治亚理工/FAIR）· 2020-04 · 代码 jacobkrantz/VLN-CE

## 基本情况

- 路线：**导航（VLN）**——库里第一条非操作线
- 一句话：把 VLN 从"全景图节点跳转"搬到**连续 3D 环境**（前进 0.25m / 转向 15°），并**量化证明之前的高分主要来自图先验**
- 只改环境不改指令：仍用 R2R 的同一批人类指令 → 两边可直接对比

## 动机：原 VLN 的三个不真实假设

| 假设 | 问题 |
|---|---|
| **已知拓扑** | agent 直接知道环境布局（连"没见过的场景"也提前知道图结构） |
| **oracle 导航** | 节点间移动确定，等于假设有完美导航器跨越数米避障 |
| **完美定位** | 随时知道精确坐标和朝向（室内 SLAM 至今仍难） |

→ 问题被简化成"视觉引导的图搜索"，不是真正的机器人导航

## VLN-CE 定义

```
环境：Matterport3D 真实 3D 扫描 + Habitat 模拟器
动作：forward 0.25m / turn-left 15° / turn-right 15° / stop
难度变化：
  · 时程暴涨：VLN 4-6 节点跳 → VLN-CE 平均 ~55 步（模型实跑 88 步）
  · 视角是 agent 动作的产物（非人类精心拍的全景）
  · 会被障碍卡住（图里结构上不可能）
  · 没有定位信息
```

## 基线模型（2020 年配方，比 VLA 落后一代）

- **Seq2Seq**：视觉特征 → GRU → 动作
- **Cross-Modal**：视觉+深度+指令 BiLSTM → 注意力 → GRU
- 无预训练 VLM、无 Transformer 大模型

训练技巧：inflection weighting（动作变化时刻加权）、DAgger（解决 exposure bias）、Progress Monitor（预测走完路径百分之几）、反向 speaker 生成约 15 万条合成轨迹

## 四个核心发现

**① 图先验值多少分**：随机"选方向然后一直往前"的 agent，在图里 **16.3%**，在连续环境里 **3%** → 13 个点是图结构白送的

**② VLN 技巧搬运效果**：
| 技巧 | 效果 |
|---|---|
| DAgger | ✅ +0.03~0.05 SPL |
| Progress Monitor | ❌ 单独用变差（过拟合） |
| 数据增强 | ❌ 单独用变差 |
| 三个全上（预训练后 DAgger 微调） | ✅ 最好 SPL 0.30 |

**③ 深度是命根子**：
| 输入 | val-unseen 成功率 |
|---|---|
| RGBD | **20%** |
| 只有深度 | 17% |
| 只有 RGB | **4%** |
| 无视觉 | **0%** |
| 无指令 | 17% |

去掉 RGB 还有 17%，去掉深度立刻 4%——深度是"不撞墙"的必需品，是能 bootstrap 的前提

**④ 跨设置直接对比**：最好模型在 VLN-CE 里 SPL 0.30；把它的路径转回图的格式丢到 VLN 榜单评，**SPL 只有 0.21**；同期 VLN 方法 0.38-0.47 → **VLN 的进步可能被高估**

## 谱系定位

- 两问：**不预测**（端到端策略，无世界模型）/ **直接控制**（走）
- 库里第一个"纯策略、无预测"的具身任务
- 操作 vs 导航对比：

| | 操作（VLA） | 导航（VLN） |
|---|---|---|
| 动作空间 | 6-7 维末端位姿 | 前进/转向离散动作 |
| 时程 | 秒级动作块 | 几十上百步 |
| 核心难点 | 灵巧、接触、精确 | **记忆、探索、定位** |
| 预测未来 | 部分预测（WAM） | 基本不预测 |

## 判断线索（本文给库的通用方法论）

**"分数里有多少是环境白送的"**：
- VLN 图先验：手工 agent 16.3% vs 3%
- Isaac Lab 的 sim2real 归因：执行器/渲染/随机化
- OpenVLA int8 掉点：1.2Hz vs 训练 5Hz 的频率偏离

→ 看论文高分时先问这个
