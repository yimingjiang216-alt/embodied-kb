怎么把三维高斯泼溅（3DGS）封装成大模型可直接调用的空间智能工具链？

答

结论

基于真实 TUM RGB-D freiburg1_desk 室内场景点云构建 MCP-3DGS 服务端：将连续三维高斯椭球场转化为 4 个标准化 JSON-RPC 空间工具，并通过三维椭球马氏距离（Mahalanobis）膨胀建图与相机视锥占空比评分，使避障轨迹安全裕度比纯点心栅格提升 125%，主动视角搜索一步信息增益超随机采样 49%。

  1. 纯高斯的质心体素化会忽略大尺度扁平椭球（桌面、显示器边缘）的物理包络，导致规划路径擦碰障碍物。1
  2. 按 $3\sigma$ 协方差椭球包络膨胀构建 ESDF 距离场后，最小避障安全裕度从 0.08 m 提升至 0.18 m（全程零碰撞）。2
  3. imagine_view 工具支持智能体在移动前合成候选相机位姿的 RGB、深度与不透明度图，单步视角覆盖增益达 0.73。2

适用于TUM RGB-D freiburg1_desk 真实点云4 个 FastMCP 工具22 项 pytest 单元测试全通

大模型智能体是怎么通过 4 个 MCP 工具完成「找物体 → 想视角 → 算路径 → 改场景」的？

图的结构
  • 具身 VLM 智能体 vlm
  • FastMCP 空间服务端 srv
  • 3DGS 场景与光栅化器 gs
  • vlm → srv · query_3d_grounding (查询软盘或键盘)
  • srv → gs · 开放词汇语义匹配 + 3D 椭球聚类
  • gs → srv · 3D 质心坐标、OBB 包围盒与置信度
  • vlm → srv · imagine_view (合成候选观测位姿视角)
  • srv → gs · 针孔投影 + Alpha 混合渲染 RGB/Depth
  • gs → srv · 视角可见占空比与遮挡诊断
  • vlm → srv · plan_collision_free_path (起点到目标)
  • srv → gs · 3σ 椭球膨胀 ESDF + 三维 A* 规划
  • gs → srv · 零碰撞平滑轨迹路点与最小安全距离
  1. query_3d_grounding ↗

    输入自然语言物体名，在三维高斯语义特征场中检索并返回米制世界坐标 (x, y, z) 与三维包围盒尺寸。

  2. imagine_view ↗

    输入候选相机位姿 (eye, target)，实时光栅化输出 RGB 图、深度图与不透明度覆盖率，辅助 VLN 主动选视角。

  3. plan_collision_free_path ↗

    基于 $3\sigma$ 高斯协方差椭球膨胀构建欧氏符号距离场（ESDF），执行三维 A* 搜索与二阶平滑。
