结论

在真实 TUM RGB-D 位姿与 7-DoF 操作轨迹上，连续 6D 位姿与二值夹爪阶跃（0 → 1）具有截然不同的频谱特性：低通频域分词（FAST-DCT）将 token 数压缩 4 倍，但直接在夹爪通道截断高频会引发 0.386 的吉布斯振铃；解耦夹爪通道或在连续流匹配后串联 4 阶残差动作精炼（Residual Action Refiner） 可同时消除振铃并压低末端误差。

  1. 在 3-DoF 导航轨迹上，3 级 RVQ 仅用 3 个 token 即达到逐维 32 档（30 个 token）同级的 1.22 cm 精度。1
  2. 在 7-DoF 操作轨迹上，将 6D 位姿走 FAST-DCT（24 tokens）、二值夹爪走游程翻转编码（2 tokens），留出集 ADE 仅 3.03 mm 且振铃归零。2
  3. 在 π0.5 流匹配（10 步 Euler）基础上串联 4 阶残差精炼头，留出集 ADE 从 10.89 mm 降至 9.27 mm，急动度降低 35.3%。2

图的结构
  • 双路相机 180度翻转 cam
  • 8维状态补零至32维离散化 state
  • PaliGemma-3B 编码 vlm
  • 300M 专家 10步流匹配 expert
  • 分位数反归一化 unnorm
  • robosuite OSC 物理步 mujoco
  • cam → state · 拼接多模态输入
  • expert → unnorm · 30步取前10步
  • state → vlm · 256档文本词元
  • unnorm → mujoco · 7维末端增量指令
  • vlm → expert · KV 缓存跨注意力
  1. 双路相机 180度翻转 ↗

    读取 agentview 与 wrist 256×256 图像，翻转 180 度修正 MuJoCo OpenGL 帧缓冲颠倒。

  2. 8维状态补零至32维离散化 ↗

    修复 LeRobot 0.6.1 状态未补零导致的注意力错位：将 8 维状态补零到 32 维再做 256 档分位数离散化，拼入文本提示词。

  3. PaliGemma-3B 编码 ↗

    视觉词元与含 32 个状态档位的文本提示词共同生成键值缓存。

  4. 300M 专家 10步流匹配 ↗

    动作专家从高斯噪声出发执行 10 步欧拉积分，生成 30×7 动作块并截取前 10 步入队。

  5. 分位数反归一化 ↗

    按训练集 q01/q99 分位数统计量还原真实物理尺度，驱动 Panda 机械臂完成 spatial/object/goal 三项任务。
