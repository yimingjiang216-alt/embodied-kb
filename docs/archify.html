四大技术主线是怎么串联 36 篇核心论文的？

图的结构

  • 全身运动控制层 wbc

  1. 具身任务规划层 ↗

    收录 SayCan、VoxPoser、X-Planner-9B（事件结构化与阶梯潜空间规划）及 X2-Turn-4B（80ms 全双工语音轮次预测）。

  2. 视觉语言动作模型 ↗

    覆盖 ACT、Diffusion Policy、RT-2、Octo、RDT-1B、AgiBot GO-1、DP3、π0/π0.5 及自变量 Wall-OSS 1.0 Lite（Qwen3.5-4B + 4 阶残差动作精炼）。

  3. 全身运动控制层 ↗

    拆解 Unitree G1 29-DoF 运动追踪：DeepMimic、AMP、BeyondMimic（引导扩散动作先验）与 SuperMimic（单一可微世界模型梯度直传）。

  4. 物理仿真与世界模型 ↗

    涵盖 MuJoCo 接触动力学、Isaac Lab、UniSim、Genie 及 Wall-WM 2.0（Qwen3.5-9B + Wan2.2 动作条件视频生成）。

  5. 三维空间表征与服务 ↗

    串联手写 RGB-D SLAM、3D Gaussian Splatting 与 MCP-3DGS（三维语义定位、视角想象、ESDF 避障规划）。
