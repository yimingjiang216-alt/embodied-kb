结论

面对 200+ 篇自称「世界模型」或「具身基础模型」的论文，本知识库用两个正交维度把 36 篇代表作摆成一张清晰的地图：横轴按「预测什么空间、结果给谁用」切成 6 档光谱（00-谱系总图），纵轴按「大脑规划 → 运动皮层 VLA → 小脑全身控制」切成三层认知架构（01-认知架构）。

  1. VLA 不是大脑，而是运动皮层：π0、OpenVLA、Wall-OSS 负责把视觉和指令变成毫秒级动作块，长程拆解与空间记忆仍需高层规划器（X-Planner-9B）与三维表征（3DGS）配合。1
  2. 动作表征的三代演进：从单步回归到动作分块与扩散（ACT / Diffusion Policy），再到离散词元（RT-2 / OpenVLA / FAST）与连续流匹配 + 链式残差精炼（π0 / Wall-OSS 1.0）。2
  3. 世界模型的两派分野：潜空间动力学派（DreamerV3 / V-JEPA 2 / SuperMimic）追求轻量可微展开以直接反传策略梯度；视频生成派（UniSim / Cosmos / DreamZero / Wall-WM 2.0）追求高保真视觉先验与虚拟交互考场。2

  1. ACT 与 Diffusion Policy ↗

    确立「一次预测整段动作块（Action Chunking）」范式，用 CVAE 或 DDPM/DDIM 解决模仿学习复合误差与多峰分布平均化。

  2. RT-2 与 OpenVLA 离散派 ↗

    将动作逐维切为 256 档并映射为词表 token，直接复用 VLM 自回归训练，但每步需串行解码 7 个 token。

  3. FAST 频域余弦分词 ↗

    利用离散余弦变换（DCT）将平滑动作块变换到频域再做 BPE 编码，大幅降低自回归 token 数量。

  4. π0 与 π0.5 流匹配派 ↗

    采用 VLM 主干 + 独立 300M 动作专家（MoT），通过 10 步流匹配积分直接输出 50Hz 连续动作。

  5. Wall-OSS 1.0 残差精炼 ↗

    基于 Qwen3.5-4B（3:1 线性注意力，256K 上下文 + 关键帧记忆），在流匹配输出后串联 4 阶残差精炼模块。

  6. BeyondMimic 与 SuperMimic ↗

    人形机器人 29-DoF 全身控制：从高方差无模型 PPO 演进为单一可微物理世界模型一阶路径导数反传（BPTT）。
